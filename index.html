Merged pack

Upload sheet = the tab you are viewing. Upload pack = every ticked tab, each saved as its own sheet. The library keeps the full version (note lengths, velocity, pedal); whoever uses it chooses which to keep. In Melochi4Luna: Add Song → Multiple → paste → Import all, or Edit.
Melochi4Luna · improved note engine

Reads the tempo from the MIDI file instead of using the BPM box. Turn it off to type your own BPM. Timing stays exact either way; BPM only sets the song's base speed in the player.

The game piano has 61 keys (C2–C7). When on, notes outside that range are moved up or down by whole octaves. When off, they are dropped.

When enabled, uses actual note durations from the MIDI. When off, notes are short taps (better for many Roblox pianos).

Translates MIDI velocity into Alt+key dynamics, only inserted when the level actually changes. Works only if the game piano supports velocity.

Converts sustain pedal (CC64) events into Space key holds. A pedal still held at the end is released automatically.
